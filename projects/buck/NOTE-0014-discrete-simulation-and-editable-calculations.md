## 问题现象

要求同时保留开环/闭环、离散、可直接打开的R2021b模型，并在方案修改后另存新参数版本、将结果加入PPT，还需要可编辑Mathcad Prime9电感计算。主要风险是文件能生成，却与实际参数或验证级别不一致。

## 原因分析

现有440 kHz版本脚本的实际设置如下，不能因旧函数/块名含“100kHz”就把它认作仍在100 kHz运行，也不能仅凭新文件名就认定内部参数已更新：

| 项目 | 已核读脚本内容 |
| --- | --- |
| 功率步长 | 1/60 MHz=16.667 ns，固定步长离散 |
| PWM | 60 MHz计数，每周期136 tick，441.176 kHz |
| 180° | 两相相差68 tick |
| 初始死区 | 3 tick=50 ns |
| 控制周期 | 544 tick=9.0667 μs，即每4个PWM周期 |
| 磁件 | 两只独立15 μH，串联参数按脚本定义 |
| Cout | 940 μF、ESR 8 mΩ；而后续硬件三只470 μF合计1410 μF |
| 控制 | 电压PID＋慢速均流；不可因块名写CV_CC就认定有独立完整CC内环 |
| 元件模型 | 简化开关Ron/反向通路，不是厂家GaN损耗/热模型 |

细步长记录、降采样日志、Scope显示分辨率是不同概念。降采样后的图看不到纹波，不证明原始开关电流没有纹波。

## 解决方案

开环验证固定占空比和输入/负载变化，不能偷偷用电压反馈修正占空比后还称开环。闭环至少覆盖启动、参考阶跃、负载阶跃、输入变化、均流及故障。

现有结果CSV曾记录32 V→18 V、220 W、15 μH时稳态约17.99998 V，两相均值约6.1089/6.1112 A；另有约11.493 μH敏感性试算。这里只说明**已有日志中的数值**，本次没有重新运行MATLAB，且模型Cout及保护门限未与最终硬件完全统一，不把这些数值当当前实板性能保证。

Mathcad应使用原生可编辑计算区域和单位，避免把公式全部作为图片。确认Prime9版本，再选择正确模板/文件格式；压缩包、XML或关系文件结构能解析，不等于已经在Prime9界面完成重算。

PPT中的拓扑、PWM、电感电流、计算过程和仿真波形应注明版本、轴、单位、工况和来源类型。硬件改动后先统一模型参数，再更新结论；用通用原创图解释原理，不把其他项目原理图改个标题当作完成新设计。

## 经验与复用条件

准备一个参数主表、测试矩阵和版本日志。记录实际fs而不是只写目标440 kHz；记录控制周期而不是让读者误以为每PWM周期都执行全部算法。普通计数比较值取整会带来占空比分辨率与限环，HRPWM是否启用也必须和目标固件一致。理想采样模型不会自动包含GS8552/霍尔延迟，也不会证明硬件比较器已接到TZ。
