## 问题现象

一次硬件方案修改不仅改变原理图。后续曾出现原理图已经修正、磁盘PCB仍停在较早版本，以及BOM仍含不相关旧器件和旧分流电阻值的情况。不断覆盖报告还容易把“曾发现”“已在SCH修正”“已测通过”混在一起。

## 原因分析

最后一次本轮静态复核的时间关系为：2026-11-26原理图12:25、PCB11:56。以下是**该历史快照**，不保证读者之后打开的工程仍是此状态。

| 事项 | 历史发现与最后一次证据 |
| --- | --- |
| 输入25 V电容用于28～32 V | 图纸主要输入电容已改50 V，仍需真实料号/容量/尺寸 |
| 输出16 V电容用于18～25 V | 主要输出电解已改50 V，C4后续也改50 V |
| IC1/U9/U10供电浮空 | 12:25原理图分别接3V3/3V3/5V；11:56 PCB尚未同步 |
| 输出电流增益0.165 | 后改200倍；15 A名义3.0 V |
| 霍尔后级3.3倍饱和 | 后改0.33倍，量程利用率需由软件/精度决定 |
| 辅助47 kΩ/10 nF | 后改100 kΩ/100 nF |
| 两相汇合 | 用户确认J1↔J3板外铜排，不能再把板内分网简单判断路 |
| 端子型号/封装 | J1/J2标T44120090-1300，选中却是M3铜柱模型，需统一 |
| 采购字段 | 借用符号遗留的厂家/MPN字段可能与Comment完全不同 |
| 3.3 V源 | 两板稳压输出需明确选一或DNP，不默认直接并联 |
| 电感 | 只有EE22外形名，尚不足证明实际15 μH、偏置及温升 |
| 输出电解尺寸 | 不只改470 μF/50 V文字；选中几何模型必须与实物匹配 |

## 解决方案

发布前至少完成：

- [ ] 统一参数、实际料号、耐压、精度、封装及安装高度。
- [ ] 明确不装件、3.3 V源和板外铜排；J2位于第一相霍尔前端，不能短接J2/J3旁路霍尔。
- [ ] 原理图注释/编译、高亮关键网，处理重复引脚编号。
- [ ] ECO到PCB，核对电源焊盘Net、元件数、端子分网和封装替换。
- [ ] 重导BOM及装配图，避免沿用旧表的器件/4 mΩ分流器等。
- [ ] 运行原生ERC/DRC，评估实际铜皮、载流、回流、散热、装配及钢网。
- [ ] 不接主功率高压，先测5 V/3.3 V及模拟量程；注入测试避免与运放输出互相驱动。
- [ ] 逐段测试软件OST、外部TZ、模拟阈值和完整故障到关波时间。
- [ ] 从低压限流到全范围加载，记录均流、峰值、超调、温升和故障保持。

证据应至少分为：用户说明、手册核对、理论计算、静态连接、原生编译、仿真记录、硬件实测。外部铜排属于已确认装配意图，不是已完成接线/载流测试。
