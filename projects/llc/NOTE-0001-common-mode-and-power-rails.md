## 问题背景

输出过压保护希望在比较器输入约 2.3～2.5V 时翻转，而比较器原计划使用 3.3V 供电。模拟采样又希望在最大被测值时输出 3.3V，容易将“供电为 3.3V”理解成“输入和输出都能准确覆盖 0～3.3V”。

本条记录整理这两个误解，并回答：单电源运放的共模输入是不是必须保持为正？

## 先区分四个量

| 概念 | 含义 |
| --- | --- |
| 供电范围 | 电源引脚允许的工作电压，例如正电源为 5V、负电源接地 |
| 输入共模范围 | 输入级能够按规定工作的共模电压区间，需要结合每个输入引脚的限制使用 |
| 差模输入 | `VIN+ − VIN−`，表示两输入之间的差值 |
| 输出摆幅 | 给定负载、供电、温度等条件下，输出能够达到的范围 |

这里用 `VS+ / VS−` 表示电源引脚，用 `VIN+ / VIN−` 表示信号输入，避免把“反相输入”误认为“负电源”。

$$
V_{CM}=\frac{V_{IN+}+V_{IN-}}{2},\qquad
V_{DIFF}=V_{IN+}-V_{IN-}
$$

负反馈、线性工作的运放通常有 `VIN+ ≈ VIN−`；比较器则经常处于较大差模输入状态，必须另外核对具体器件的输入规则。

检查顺序：供电工作范围 → 输入共模及各引脚限制 → 差模限制 → 所需输出摆幅 → 后级 ADC 允许范围。

## 原因一：LM293 的有效输入范围没有一直延伸到正电源

TI LM293 数据手册第 5.8 节给出的共模上限：25℃为 `VCC − 1.5V`，全温范围为 `VCC − 2V`。[资料：LM293 数据手册](https://www.ti.com/lit/ds/symlink/lm393.pdf)

| 供电 | 25℃共模范围 | 全温共模范围 |
| --- | --- | --- |
| 3.3V | 0～1.8V | 0～1.3V |
| 5V | 0～3.5V | 0～3.0V |

例如，两个输入分别为 2.500V、2.510V，差值只有 10mV，但共模约 2.505V。3.3V 供电时不能保证这个门限附近的正确比较；5V 供电时，这两个输入位于有效区间。

手册还给出一项特例：一个输入处于有效范围时，另一输入可升至 VCC，并保持正确输出。该条件不能推广到所有比较器或运放，也不能解释成两个输入均可任意越界。

超过工作范围可能导致错误比较；绝对最大额定值描述的是应力限制，不等于正常工作保证。

## 处理方案：比较器 5V 供电，开集电极输出上拉至 3.3V

LM293 输出为开集电极，只主动拉低或释放输出。芯片供电与输出高电平可以分别确定：

```text
5V ------------------ LM293 VCC

3.3V --- Rpullup ---+--- DSP TZ 输入
                   |
                LM293 OUT

GND ----------------- LM293 GND
```

输出高电平由 3.3V 上拉确定；低电平由比较器灌电流产生，仍应核对 VOL、上拉电流和 DSP 的 VIL。此接法不能套用于普通推挽运放输出。

案例中的标称方案为：比较器 5V 供电，输出上拉 3.3V，独立电压分压采用上臂 6.8kΩ、下臂 3.3kΩ。若参考为 2.5V，则理想过压点为：

$$
V_{OVP}=2.5\times\frac{6.8+3.3}{3.3}\approx7.65V
$$

实际阈值还需考虑参考、电阻、失调和温度误差。供电修改并不会自动修改参考电压。

## 原因二：轨到轨输入与轨到轨输出是不同指标

OPA365 支持 2.2～5.5V 供电，规定的输入共模范围为 `VS− − 0.1V` 至 `VS+ + 0.1V`。因此它可以接收接近地和正电源的输入。[资料：OPA365 数据手册第 7.6 节](https://www.ti.com/lit/ds/symlink/opa365.pdf)

输出仍有距离电源轨的余量，且受负载和温度影响。手册列出的典型 10mV、最大 20mV 输出轨余量有明确测试条件：5.5V 供电、10kΩ 负载等，不能直接当成所有供电和负载条件下的固定数值。

### 对本项目的影响

| 场景 | 判断 |
| --- | --- |
| 5V 输出经 6.8kΩ / 3.3kΩ 分压，约得到 1.63V | 修正后的 OPA365 跟随器使用 3.3V 供电有输出余量 |
| 10.1V 分压后要求输出 3.300V | 若运放仅供电 3.3V，不能保证准确到达该端点 |
| 电流调理要求最大电流时输出 3.300V | 同样需要检查正电源轨余量 |
| 将运放改为 5V 供电 | 3.3V 输出有更多余量，但异常时输出可能高于 ADC 允许值，需要设计输入保护 |

升高供电不能修复采样电路的极性、增益或零点错误。另一条可行路线是保持 3.3V 供电，把正常最大输出设计在约 3.0V，并按真实比例校准软件。

## 问答：单电源运放的共模输入必须为正吗？

**不必严格大于 0V；必须落在该器件规定的共模范围内。**

单电源一般指 `VS− = 0V`、`VS+ > 0V`。这并没有给所有器件规定同一个输入下限：

- 输入范围包含地的器件，可以在满足其他条件时处理接近 0V 的输入。
- 有的器件下限高于地，哪怕输入是正电压，也可能不满足要求。
- OPA365 明确允许共模略低于负电源轨；该小范围能力不能推广成能够直接测量任意负电压。

“共模为正”也不是充分条件。例如两个输入分别为 +3V 和 −1V，平均为 +1V，仍不能凭这个平均值认定输入合法；需要检查每个引脚和差模应力。

输入端名字 `IN−` 表示反相输入，不表示它必须接负电压。差模为负，也不等于共模为负。

### 外部负信号与芯片输入引脚负电压的区别

采用输入范围包含地的运放时，理想反相放大器可以把外部 `−0.1V` 经输入电阻送入求和节点；若 `Rf/Rin = 10`、同相端接地，则目标输出为 `+1V`，两个芯片输入端在正常负反馈下均接近 0V。

这个例子中外部信号为负，但芯片输入共模接近地。是否实际可用，仍取决于输入范围、输出范围、误差和瞬态条件。

若需要保留双向信号而输出又只能在正电压范围内变化，通常要添加直流偏置，例如把交流波形中心抬到 1.65V，并保证整个波形不越过输入和输出范围。
